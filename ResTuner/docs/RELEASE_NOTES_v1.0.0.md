## 它能做什么

7-Zip 那套"复古"界面，本质是 PE 文件里的资源：

| 文件 | 资源 | 效果 |
|---|---|---|
| `7z.dll` | `RT_ICON` + `RT_GROUP_ICON`（27 个格式） | 资源管理器里 `.7z` / `.zip` / `.rar`… 的文件图标 |
| `7zFM.exe` | `RT_BITMAP` 100–106 / 150–156 | 文件管理器工具栏的 7 个按钮（大/小两套） |

原版每个格式只有 32×32 / 16×16 两个 8bpp 小图标；本工具换成 **8 种尺寸**
（256/64/48/40/32/24/20/16，32bpp，256 用 PNG 压缩）。

## 主要特性

- **一键**：自动探测 7-Zip 安装目录 → 体检 → 备份 → 打补丁 → 自检 → 写回
- **会跟新版走**：图标索引映射从目标文件自己的 `RT_STRING` 读取，7-Zip 新增格式能自动跟上
- **已验证版本**：`25.01`、`26.05`（附结构指纹校验）；其他版本按结构自适应，需勾选确认
- **最小改动**：`7zFM.exe` 走等尺寸原地覆盖，**节表与头部完全不动**；只有 `7z.dll` 重建 `.rsrc`
- **写回前自检**：重新解析、比对资源集合、确认未参与替换的资源逐字节未变，不通过就不写盘
- **可回滚**：自动备份到 `.restuner-backup\`，一键还原并校验 SHA-256
- **零第三方依赖**：纯 Python 标准库

## 使用

1. 照常安装官方 7-Zip（x64）
2. 运行 `ResTuner.exe`（写 `C:\Program Files` 需管理员：界面右下角「以管理员身份重启」）
3. 点 **应用主题** → 按提示 **刷新图标缓存**；必要时重启资源管理器

## 顺带修掉的三个问题

对着社区现有补丁做逆向时发现三处缺陷，本版本都不复刻：

1. `7zFM.exe` 的 `RT_GROUP_ICON #100` 高度被写成宽度（110×63 → 110×110）
2. `RT_VERSION` 被"重新编译"改了 4 个字节（本工具原样保留）
3. `7z.dll` 的 arj 图标组残留 2 个旧 8bpp 图标（本工具按引用关系清理干净）

## 已知限制

- 仅支持 **x64**（`PE32+`）；检测到 32 位会直接拒绝，不会产出坏文件
- 目标带数字签名时，改完签名必然失效，工具会剥离签名表并在日志说明
- 只处理 `7z.dll` + `7zFM.exe`；`7zG.exe` / `7-zip.dll` / SFX 暂未覆盖
- 图标缓存很顽固，改完若"看着没变"，刷新缓存或注销一次
